# Навык: результат без разрывов

Проверьте четыре слоя:

1. Функциональный — результат действительно существует и работает.
2. Пользовательский — человеку понятно, где он и что делать дальше.
3. Доказательный — есть проверяемое подтверждение результата.
4. Передача — другой человек может продолжить работу без скрытого контекста.

Если хотя бы один слой не закрыт, задача ещё не завершена.
