# Навык: проверка гипотезы на опровержение

1. Запишите гипотезу одним предложением.
2. Назовите факт, который её опровергнет.
3. Зафиксируйте исходное состояние.
4. Проведите минимальную проверку.
5. Сравните результат с критерием.
6. Дайте один из трёх итогов: подтверждено, частично подтверждено, опровергнуто.

Запрещено заменять фактическую проверку предположением.
