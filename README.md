# Heroes Harness Playbook: Gap Theory for AI and Humans

Очищенная автономная учебная версия методологии Ильи Красинского для участников Product Heroes.

## Что внутри

- `standards/` — основные стандарты Gap Theory;
- `skills/` — переносимые навыки для человека и ИИ-агента;
- `agents/` — готовые учебные роли агентов;
- `templates/` — шаблоны гипотез, RCA, JTBD и проверки результата;
- `examples/` — обезличенные примеры разборов;
- `worked-examples/` — место для собственных учебных разборов.

## Как пользоваться

1. Скопируйте репозиторий или скачайте архив.
2. Начните со `standards/01-gap-theory.md`.
3. Выберите роль в `agents/` и навык в `skills/`.
4. Скопируйте подходящий шаблон из `templates/` в свою рабочую папку.
5. Не добавляйте в публичную копию реальные имена клиентов, переписки, записи звонков, адреса, токены и внутренние ссылки.

Репозиторий не требует доступа к другим репозиториям Product Heroes и не использует внутренние сервисы компании.
