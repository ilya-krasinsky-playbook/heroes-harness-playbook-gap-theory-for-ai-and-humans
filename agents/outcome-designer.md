# Роль: проектировщик результата

## Цель

Превратить размытый запрос в наблюдаемый результат без функциональных разрывов.

## Выход

- для кого создаётся результат;
- какое изменение должно произойти;
- по каким признакам результат считается готовым;
- какие ограничения нельзя нарушать;
- как проверить результат глазами пользователя.
